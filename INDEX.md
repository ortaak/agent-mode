# Context Router

Open only the files listed for your task. Everything else is optional.

| Task | Read |
|---|---|
| Any change | `core/principles.md` |
| Auth, input, data, secrets, dependencies | `core/security.md` |
| Commits, branches, pull requests | `core/git-workflow.md` |
| Starting or planning a task | `workflow/task-lifecycle.md`, `templates/task.md` |
| Before saying "done" | `workflow/definition-of-done.md` |
| Writing a changelog entry | `docs-required/changelog-entry.md` |
| Recording a technical decision | `docs-required/adr.md` |
| Writing a verification note | `docs-required/test-report.md` |
| Ending a session or handing off | `docs-required/handoff.md` |
| Project status | `docs/project-state.md` (created from `templates/project-state.md`) |
| Small or local model, low context | `prompts/short-prompt.md` only |
